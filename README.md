# 📰 AI 뉴스 요약 프로젝트 (String Time News)

뉴스 기사를 자동으로 수집·분류·요약하고, 대시보드로 시각화하는 서비스입니다.

> 3인 팀 프로젝트로 진행했으며, 이 브랜치(`main`)에는 **본인이 담당한 백엔드 작업**이 담겨 있습니다.
> 프론트엔드까지 병합된 완성본은 [`feat/frontend` 브랜치](../../tree/feat/frontend)에서 확인할 수 있습니다.

---

## 담당 역할

- 백엔드 전체 설계 및 팀 리드

## 주요 기능 (백엔드)

| 기능 | 설명 |
|---|---|
| 중복 뉴스 제거 | TF-IDF 코사인 유사도 기반 유사 기사 필터링 |
| 다중 레이블 분류 | 기사 하나가 여러 카테고리에 속할 수 있도록 분류 |
| 계층적 클러스터링 | 관련 뉴스를 주제별로 그룹핑 |
| 자동 요약 | Ollama를 활용한 데일리 뉴스 요약 생성 |
| API 서버 | FastAPI 기반으로 프론트엔드에 데이터 제공 |

## 기술 스택

`Python` `FastAPI` `scikit-learn (TF-IDF, 클러스터링)` `Ollama`

## 프로젝트 구조

```text
crawler_mvp.py   # 뉴스 크롤링
backend/         # API 서버 및 분류·클러스터링·요약 로직
```
